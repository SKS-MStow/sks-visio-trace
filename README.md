# SKS drawings viewer: mockups

Design study for the SKS Field Dashboard's drawings viewer. It shows every drawing in a job in one strip, with a mode per drawing type:

- **Schematics:** cable trace and filtering.
- **Elevations:** layer hide/show.
- **Floor plans:** rooms and device types.

Live: https://sks-mstow.github.io/sks-visio-trace/

The drawings are a real SKS kit-built set, **anonymised** as "Demo Client": the client name, address and quote numbers have been removed from the files, not just covered. The floor plan is a demo sheet drawn in the SKS equipment-plan style.

Static site, no build step. Open `index.html`, or `viewer.html` for the viewer itself.
